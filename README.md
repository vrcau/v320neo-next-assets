# v320neo-next Assets Github Release Host Repository

This repository are used to host assets package (models, sounds and texture) for [v320neo-next](https://github.com/vrcau/v320neo-next) in [Github Releases](https://github.com/vrcau/v320neo-next-assets/releases).

The git repository of this repository won't host any assets files, it only contains this document and CHANGELOG of the assets package.

## Download Assets package

Go to [Github Releases](https://github.com/vrcau/v320neo-next-assets/releases) and download the version you need.
